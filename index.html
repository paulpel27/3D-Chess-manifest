Install as Local Desktop App

Install Grandmaster 3D Chess as a standalone local application window on your computer.

How to Install as a Standalone Local App:
  1. Option A (1-Click Windows App): Double-click Install-Local-App.bat in C:\Users\pelpa\.gemini\antigravity\scratch\chess-3d-pwa (or click the gold button above and run the downloaded file). It generates icon-192.png & icon-512.png, starts the background server, and opens the standalone App Window.
  2. Option B (Browser PWA): Double-click Start-PWA-Server.bat to open http://localhost:8080, then click 📲 Install Local App Now.
